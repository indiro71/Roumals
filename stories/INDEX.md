# Каталог историй

## Структура

```text
stories/
  standalone/<название>/
    brief.md
    script.md
    generation.md
  series/<название>/
    SERIES.md
    CONTINUITY.md
    episodes/001-<название>/
      brief.md
      script.md
      generation.md
  arcs/<название>/
    ARC.md
    CONTEXT.md
    TIMELINE.md
  templates/
  INDEX.md
```

`standalone/` — самостоятельные короткометражки, `series/` — сериалы, `arcs/` — долгосрочные сюжетные линии. Папки пока пусты: конкретные истории ещё не созданы.

Сериал может состоять из независимых эпизодов, развивать общий сюжет или совмещать оба подхода. Одна история может развивать несколько линий. Линия может объединять несколько работ только при явно указанном общем мире и согласованной связи.

## Создание материалов

1. Согласовать с пользователем задачу и объём работы по `AGENTS.md`.
2. Выбрать раздел и создать папку с устойчивым понятным именем, например `first-snow`. Нумеровать серии с ведущими нулями: `001-first-snow`.
3. Скопировать подходящие документы из [templates](templates/). Для мультфильма или серии нужны `brief.md`, `script.md`, `generation.md`; для сериала дополнительно `SERIES.md`, `CONTINUITY.md`; для линии — `ARC.md`, `CONTEXT.md`, `TIMELINE.md`.
4. Заполнить поля шаблонов и добавить реальные относительные ссылки между документами и на персонажей. Неизвестные данные отмечать «не определено», отсутствие связей — «нет».
5. Добавить запись в этот каталог. Для серии также обновить список эпизодов в `SERIES.md`.
6. При подготовке сценария прочитать относящийся к нему контекст. После явного утверждения пользователем зафиксировать версию и обновить контекст и хронологию по правилам проекта.

## Статусы и источники контекста

Сценарии проходят статусы: **идея → черновик → на согласовании → утверждён**. Только явно утверждённая версия является источником произошедших событий. Статус генерации хранится отдельно в `generation.md`.

`CONTINUITY.md` хранит сводное состояние сериала, `CONTEXT.md` — подробности отдельной линии, `TIMELINE.md` — последовательность её событий. Источником фактов остаётся утверждённый сценарий; в сводках обязательны ссылки и версии.

При изменении утверждённого сценария сначала сохранить его предыдущую версию рядом под именем `script.vNNN.approved.md`, затем редактировать `script.md` как следующую черновую версию. Ссылки на старый канон направить на сохранённую версию. Пока новые правки не утверждены, контекст остаётся основанным на предыдущей утверждённой версии.
